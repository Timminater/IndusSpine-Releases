# IndusSpine 0.3.11

## Nederlands

gestopte worker zijn geladen extensiemodules heeft vrijgegeven. Een venv-

## English

This release contains core and official companion `0.3.11`. Siemens S7
Classic and Enhanced are `0.1.15` and accept core API `0.3.11`.

Removing a driver package on Windows now waits, within a bound, until a
just-stopped worker has released its loaded extension modules. A Windows venv
`python.exe` is a launcher; the real interpreter exits shortly after the
launcher, so removal right after a stop could fail with `Access is denied`.
Only that transient sharing violation is retried for up to five seconds; other
errors fail as before.

For Linux, the release gates now provision a short-lived CI host identity
next to the CI trial key, the same way `prepare.sh` does for installations;
the negative start check without a driver factory uses its own installation
directory. A failed release smoke now shows the end of the API log. Licensing
code and fail-closed gates are unchanged.

The immutable releases v0.3.7 through v0.3.10 remain preserved but produced no
artifacts.
