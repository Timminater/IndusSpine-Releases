# IndusSpine 0.3.6

- Ubuntu amd64 installation package for Docker Compose, with SQLite by default and a PostgreSQL option. The app and Caddy run together in one container; PostgreSQL optionally uses a second container. Data directories persist on the host; `prepare.sh` prepares the installation. See the included installation guide for configuration, backup and restore.
- The app periodically checks for public releases and shows an informational notice. The check uses the configured internet proxy and trusted CA configuration; no custom CA is bundled. Updates are not installed automatically. License status appears in a compact bar.
- After verified paid activation, trial license deadlines are replaced by the paid license deadlines. A problem that could leave the separate proxy unavailable after an app restart has also been addressed.
- PostgreSQL and QuestDB validation in the setup wizard has been fixed.
- V2 deactivation uses the existing 28-day grace period; the license policy is unchanged.
- License availability status correctly uses the packaged truststore. Initialization of new Docker data directories and the message after deactivation have also been improved.
- The package contains the compiled application and five official driver bundles: Modbus TCP, Siemens S7 Classic, Siemens S7 Enhanced, TCP Receive and UDP Receive.

Ubuntu 24.04 LTS amd64 is the intended platform. Before installation, verify the download against the published SHA-256 checksums and follow the included installation guide.

The [Docker installation guide](https://www.indusspine.nl/documentation/docker) covers Compose installation, host data directories and activation steps.
