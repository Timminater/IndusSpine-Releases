Storage inherits the configured PostgreSQL connection and checks it without changing data when opened. Save and continue tests writing and read-back. The base address opens the web interface. Hidden license/connection fields no longer occupy space.

Extract the Unraid kit into a **new directory**, such as `/mnt/user/Docker/indusspine`. Read `INSTALL.md`, verify checksums, run `prepare.sh` with your server address, then `docker compose pull` and `docker compose up -d --wait`. No local build or GitHub login is needed. Both images are pinned by digest; PostgreSQL exposes no host port.

Before upgrading, back up app data, a consistent PostgreSQL dump, `.env`, external trial key and host identity together. Do not unpack a fresh-install kit over an existing installation. Starting a trial clears that installation's measurements, spool and buffers; this release/update does not start a trial.
