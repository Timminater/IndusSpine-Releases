## English

This release contains core and official companion `0.3.12`. Siemens S7
Classic and Enhanced are `0.1.16` and accept core API `0.3.12`.

**Web access.** IndusSpine listens on HTTP port 8080 by default. HTTPS (port
8443) is an administrator setting under Management → System settings → Web
access, with a locally generated or an uploaded certificate. "Force HTTPS"
redirects HTTP to HTTPS and makes sign-in cookies Secure, only while HTTPS is
actually running; no HSTS is set. The Compose package no longer uses Caddy and
follows `ghcr.io/timminater/indusspine:latest`; updating is
`docker compose pull && docker compose up -d`. The package is now a separate
release asset (`indusspine-0.3.12-compose.tar.gz`).

**Users and access.** New LDAP/Active Directory user source (LDAPS or
StartTLS required): LDAP first, then local accounts; a first LDAP sign-in gets
the Reader role. Users, roles, access and user sources share one tabbed page;
other users' sessions can be ended; custom roles are editable (without
privilege escalation). The audit log is paginated (25/50/100/250, default 50)
and filterable.

**Drivers.** An installed driver is active immediately; onboarding shows
per-driver progress. Installation is about three times faster: driver
runtimes no longer get their own pip copy.

**Backup.** During a historian backup the SQLite buffer holds new
measurements; acquisition does not stop. "Revisions" and "Backup and restore"
are merged.

**Fixes.** The compiled Linux build falls back to the bundled `tzdata`
(onboarding returned 503); the release image no longer contains the CI smoke
configuration; a first trial on a clean installation no longer asks for a
reset confirmation; a fresh installation without devices shows "No devices
yet" instead of an error.
