# IndusSpine 0.3.4

Published on 28 October 2026 for Linux amd64.

- Linux release with five native driver bundles: Modbus TCP, Siemens S7 Classic, Siemens S7 Enhanced, TCP receive and UDP receive.
- The original release also contains an Ubuntu package and SHA-256 checksums. The Ubuntu package is not yet available in this catalog while its associated image is reviewed.
- Paid licensing and production activation require separately provisioned signed entitlement material and validated production endpoints.
